# Task Specifications

- `active/`: controller-approved work currently executing in Alpha Factory.
- `planned/`: drafts and sequenced work not yet active.
- `completed/`: closed tasks with commits, reports, results, and decisions linked.

Moving a task between states must preserve its history. Prefer an additive status record or commit trail over rewriting why the task existed.

`tasks/planned/P0_7E_ALPHA_RESEARCH_V2.md` is retained as a historical design artifact because it was already linked by prior ledger commits; its authoritative completion record is in `tasks/completed/`. The active planned design is `P0_8A_FACTOR_ZOO_BUILD_V1.md`.
